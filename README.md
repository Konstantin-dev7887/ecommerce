Реализованы базовые сущности ядра интернет-магазина:

Product: товар (валидация данных, приватная цена с getter/setter, создание из словаря new_product, строковое представление, сложение товаров)
Наследники Product: Smartphone, LawnGrass. Ограничение сложения только для одинаковых классов. Проверка типов при добавлении в категорию
Category: категория товара (приватное хранение списка товаров, добавление товаров через add_product, вывод товаров через property)

Автоматический подсчёт:
Category.category_count - количество созданных категорий (статический счётчик)
Category.product_count - количество товаров (суммарно по спискам products в категориях)

Отчёт покрытия тестами (HTML): poetry run pytest --cov=src --cov-report=html (результат в папке htmlcov/)
